# Phase B — Metric Definition

## Qualitative Concept

Most Valuable Offensive Player

## Operational Definition

For this analysis, the "Most Valuable Offensive Player" is defined as the
player with the highest total points, where:

Points = Goals + Assists

Total points are used as the primary measure because they capture both
scoring and playmaking contributions.

## Supporting Metrics

The following statistics will be used to provide additional context:

- Goals
- Assists
- Points
- Shots
- Shooting Percentage
- Shots on Goal
- Shots-on-Goal Percentage

## Ranking Rule

Players will be ranked primarily by total points.

If two players have the same number of points, the player with more goals
will rank higher.

If points and goals are both tied, the players will be considered equally
ranked rather than forcing an arbitrary distinction.

## Validation

The metric will be validated against the Phase B player statistics generated
from the 2013 Syracuse Women's Lacrosse dataset.

The model will be instructed to use this definition when answering judgment
questions so that its recommendation can be compared against the calculated
statistics rather than relying on an undefined interpretation of
"valuable."
